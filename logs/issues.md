# 问题与缺陷跟踪 Issues

> **规则**:开发/测试中发现的任何缺陷先登记于此(哪怕暂不修),再进入处理流程(docs/07 §5)。
> S1/S2 未关闭时,暂停新任务开发。

## 严重度定义

| 级别 | 定义 |
| --- | --- |
| S1 | 阻断:核心闭环无法进行 / 工程无法运行 / 崩溃 |
| S2 | 严重:FR 功能不可用且无替代路径 |
| S3 | 一般:功能异常但有替代路径,或非核心功能失效 |
| S4 | 轻微:表现/体验问题,不影响功能 |
