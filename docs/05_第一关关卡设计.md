# 05 第一关关卡设计:第一次回声(The First Echo)

> 版本 v1.0 | 状态:定稿 | 日期 2026-11-04
> 上位文档:第八章「第一关详细设计方案」。本文档在其基础上补充网格布局、完整文案与边缘规则。

## 1. 关卡基本信息

| 项目 | 设定 |
| --- | --- |
| 关卡名称 | 第一次回声(The First Echo) |
| 所属章节 | 第一章:苏醒 |
| 定位 | 核心玩法教学关卡 + 核心技术验证关卡 |
| 预计游玩时长 | 5—8 分钟 |
| 难度 | 极低 |
| 核心目标 | 玩家理解并成功完成一次完整的「记录 → 回声 → 协作」闭环 |

## 2. 关卡剧情

玩家进入地下研究所初始区域,前方安全门紧闭,门旁有一个压力开关:踩住开关门开,离开门关——玩家无法既踩住开关又穿过门。玩家在附近发现一台仍可运行的时间记录装置,按提示记录自己「踩上开关」的行动,生成回声;回声重演动作并持续踩住开关,玩家即可穿过安全门,抵达出口完成第一关。

## 3. 场景结构与网格布局

### 3.1 功能区域(上位文档表 11)
| 区域 | 功能 |
| --- | --- |
| A 出生区域 | 玩家初始位置,引导向前探索 |
| B 压力开关区域 | 出生区与安全门之间,学习开关并在此完成记录 |
| C 安全门区域 | 房间中部,受开关控制 |
| D 出口区域 | 门后,进入即通关 |

### 3.2 等距网格布局建议(房间 12×8 格,基准格 64×32)

```
        (北)出口区 D:格 (5,0)-(7,0)
   ┌──────────────────────────────────┐
   │            [出口触发区]           │
   │               ┌──┐               │
   │               │门│ C:格 (5,2)    │
   │               └──┘               │
   │                                  │
   │       [开关] B:格 (5,4)          │
   │                                  │
   │ [装置] 格 (3,5)                  │
   │                                  │
   │      [出生点] A:格 (2,7)         │
   └──────────────────────────────────┘
```
- 出生点 (2,7);记录装置 (3,5) 贴西墙;压力开关 (5,4);安全门 (5,2);出口触发区 (5,0)-(7,0)。
- 全部对象按统一等距网格摆放(上位文档要求);开关与门之间留 ≥2 格纵深,保证「踩开关→门开」的因果清晰可见。

## 4. 机关与交互对象

| 对象 | 功能规则 | 视觉反馈 |
| --- | --- | --- |
| PressureSwitch | 玩家或回声进入触发区即激活;所有有效对象离开后关闭 | 灰底座+指示灯灭 → 激活时灯变黄 `#F4D35E`、底座下沉 2px、播放音效 |
| SecurityDoor | 开关激活时开启,关闭时阻挡 | 关闭=红色状态灯;开启=门体上移、灯变绿、机械音效;防夹规则见 02 §7.2 |
| TimeRecorderDevice | 靠近时提示记录功能(纯提示,不需要额外终端交互) | 终端屏幕闪烁 |
| ExitArea | 仅玩家(mask=2)进入触发通关 | 无独立外观,出口区可用灯光变化示意 |

## 5. 操作流程(七阶段,上位文档表 13)

| 阶段 | 玩家操作 | 系统反馈/完成条件 |
| --- | --- | --- |
| 1 进入房间 | 出生,用 WASD 移动 | 门关、开关灭、回声数 0;HUD 显示移动提示 |
| 2 学习开关 | 踩上开关,再离开 | 踩上→开关亮、门开;离开→复位;显示「无法同时踩住开关并通过门」 |
| 3 发现记录装置 | 靠近装置 | 显示记录功能提示(见 §6) |
| 4 记录行动 | 按 R 开始 → 走上开关短暂静止 → 按 R 结束 | HUD 显示「正在记录」与进度;建议动作 3—5 秒 |
| 5 生成回声 | 按 Space | 回声从记录起点出现,青蓝色重演行动,停在开关上 |
| 6 完成协作 | 离开开关,穿过安全门 | 回声维持开关激活,门保持开启;玩家抵达门后 |
| 7 关卡完成 | 进入出口触发区 | 显示通关文案(§6),写入存档 |

## 6. 文案清单(UI 文案唯一来源,实现于 `ui_text.gd`)

| 编号 | 触发时机 | 文案 |
| --- | --- | --- |
| T-01 | 阶段1 常驻键位提示 | `WASD 移动 · R 记录 · 空格 回声 · X 删除回声 · Backspace 重置 · Esc 暂停` |
| T-02 | 首次踩上开关后离开 | `你无法一边踩住开关,一边穿过安全门。` |
| T-03 | 靠近记录装置 | `检测到时间记录设备。该设备能够记录并重现你的行动。按下 R,开始记录。` |
| T-04 | 记录中(HUD) | `正在记录 {剩余秒}s · 按 R 结束` |
| T-05 | 记录结束后 | `记录完成。按 空格,播放这段记录。` |
| T-06 | 回声数达到上限按 Space | `回声数量已达上限(3)。按 X 可删除回声。` |
| T-07 | 通关 | `第一次回声已成功建立。你发现,过去的行动可以改变现在。` + `—— 第一关 完成 ——` + `按任意键重玩` |

## 7. 状态设计(上位文档表 14)

| 状态 | 玩家/回声行为 | 机关状态 |
| --- | --- | --- |
| A 初始 | 玩家正常移动,无回声 | 开关关,门关 |
| B 开关激活 | 玩家站在开关上 | 开关亮,门开 |
| C 记录中 | 玩家行动被采样 | 记录数据累积 |
| D 回声生成 | 回声读记录回放 | 回声沿轨迹移动 |
| E 回声控机关 | 回声停在开关,玩家离开 | 开关持续激活,门保持开启 |
| F 通关 | 玩家进入出口 | 触发完成流程 |

## 9. 边缘规则(测试依据,对应 08 用例)

| 编号 | 规则 |
| --- | --- |
| E-01 | 记录中按 Backspace 重置:丢弃未完成记录,回到初始状态 |
| E-02 | 记录未结束(含记录中)按 Space:忽略,不生成回声 |
| E-03 | 记录满 30 秒:自动结束并提示可播放(T-05) |
| E-04 | 已有 3 个回声再按 Space:忽略并提示 T-06 |
| E-05 | 回声回放期间玩家可再次开始记录(允许,为第 3 关多记录铺路) |
| E-06 | 门洞内有实体时收到关闭请求:门保持开启直到清空(02 §7.2) |
| E-07 | 玩家站在开关上时开始记录:允许;记录数据正常含站立帧 |
| E-08 | 重置后立即再次记录/回放:无前局残留(残留检测见 TC-20) |
| E-09 | 记录中通关出口不可到达(门关)不成立场景:出口仅门后,天然屏蔽;若未来关卡出口裸露,通关时若在记录中则先静默结束记录(预留规则) |
