# 11 第二关关卡设计:双重行动(Two Switches)

> 版本 v1.0 | 状态:评审中 | 日期 2026-11-05
> 章节规划:docs/10;模板:docs/05。回声上限 **2**;目标时长 **3—4 分钟**;难度 低。

## 1. 关卡基本信息

| 项目 | 设定 |
| --- | --- |
| 关卡名称 | 双重行动(Two Switches) |
| 章节 | 第一章:苏醒(第 2 关) |
| 回声上限 | 2(本关新开放第 2 个回声) |
| 定位 | 多开关同步教学 + 回声组合入门 |
| 核心目标 | 玩家学会:记录一条路线让回声踩住开关 A,同时自己去处理开关 B——两个行动并行 |

## 2. 关卡剧情

配电室的两道电闸分别控制安全门左右两半锁栓。单踩任何一闸,只有半边锁舌缩回——门纹丝不动。玩家必须让"过去的自己"踩住一个闸,自己去踩另一个:第一次,两个自己同时行动。

## 3. 场景结构与布局(12×8 格,等距 64×32)

```
              北:出口区 (6,0)            安全门 (6,2) 嵌北横墙
        开关B (8,4)                    开关A (4,4)
                   中央空场(观察与跑位)
        记录装置 (2,5)      出生点 (2,6)
```

| 区域 | 格位 | 功能 |
| --- | --- | --- |
| 出生区 | (2,6) | 出生即正面看到双开关与双灯门 |
| 开关 A(西) | (4,4) | 踩上→门左指示灯亮 |
| 开关 B(东) | (8,4) | 踩上→门右指示灯亮 |
| 安全门 | (6,2) | 嵌北横墙;**AND 逻辑:两灯全亮才开启** |
| 出口区 | (6,0) | 门后一格,进入即通关 |

设计要点:A、B 与门呈对称三角形,出生点居中偏南——玩家第一眼能同时看到全部要素;A、B 之间距离约 4 格,单人无法先后兼顾(离开即释放),逼出回声方案。

## 4. 机关与交互对象

| 对象 | 规则 | 反馈 |
| --- | --- | --- |
| PressureSwitch ×2 | 复用第一关契约;分别命名开关 A/B | 激活变黄下沉(同 L1) |
| SecurityDoor | **AND 聚合**:A、B 同时激活才开启(由 Level02Manager 聚合两路信号后调 set_open) | 门体两侧**双指示灯**:左灯=A、右灯=B;全亮才开 |
| TimeRecorderDevice | 复用 L1 装置(首次靠近提示通用操作) | 屏幕闪烁 |

## 5. 操作流程(对应用户六步结构)

| 步骤 | 玩家操作 | 反馈/完成条件 |
| --- | --- | --- |
| 1 观察 | 出生,环视 | HUD 键位常驻;看到双开关+双灯门 |
| 2 发现 | 踩 A→门左灯亮但不开;踩 B→右灯亮左灯灭 | 触发 T-12「门的两半锁栓需要同时缩回。」 |
| 3 记录 | 走到 A 上,R 开始→静止 1s→R 结束 | 记录"站上 A"的动作(T-05) |
| 4 回放 | Space → 回声踩住 A | 左灯常亮;玩家自由——**发现新可能** |
| 5 组合 | 走到 B 上 R 记录→回车确认?否——直接 Space 生成第二个回声踩 B | 双灯全亮→门开(第 2 个回声开放) |
| 6 通关 | 穿门进 (6,0) | LEVEL_COMPLETED → 存档 → 通关界面「按任意键进入下一关」 |

注意步骤 5:录制 B 的路线时,回声 1 正踩着 A(时序意识第一次出现:回放会与你并行运行)。

## 6. 状态设计

| 状态 | 开关A | 开关B | 门 | 说明 |
| --- | --- | --- | --- | --- |
| 初始 | 关 | 关 | 关 | — |
| 单踩 | 开/关 | 关/开 | 关 | 任一单踩→门不开(教学核心) |
| 双踩 | 开 | 开 | **开** | 回声+玩家 或 双回声 |
| 通关 | 开 | 开 | 开 | 冻结+结算 |

## 9. 边缘规则

| 编号 | 规则 |
| --- | --- |
| E-21 | 记录 B 路线时回声 1 正踩 A:回放与记录并行(已支持,E-05)——本关核心体验,必须无卡顿 |
| E-22 | 玩家踩 B 的同时回声 1 离开 A(回声被删/重置):门立即关闭;若玩家在门洞内→防夹规则生效 |
| E-23 | 双回声 + 玩家第三处踩踏不改变门状态(上限 2,玩家踩踏只是临时点亮) |
| E-24 | 重置:双开关/双灯/门/回声/记录全量复位 |
