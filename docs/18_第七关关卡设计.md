# 18 第七关关卡设计:相位回廊(The Phase Corridor)

> 版本 v1.1 | 状态:已交付 | 日期 2026-11-08
> 章节规划:docs/17;模板:docs/16。回声上限 **3**;目标时长 **5—8 分钟(首通硬下限 5 分钟)**;难度 中高。
> **新机关首秀关**:相位门 PhaseGate、悖论区 ParadoxField(docs/17 §5);复用压力开关/安全门/能量核心。

## 1. 关卡基本信息

| 项目 | 设定 |
| --- | --- |
| 关卡名称 | 相位回廊(The Phase Corridor) |
| 章节 | 第三章:昨日回声(第 7 关) |

| 核心目标 | 玩家让两条回声分别替自己踩住被相位封锁的 S1 与悖论区深处的 S2,自己与两条时间线错峰穿区,抵达出口 |

## 2. 关卡剧情

核心实验室的外围回廊仍由自动化安保把守——但封锁的对象写着「实体」。时间异常在这里呈现出最终形态:走廊中段的空间与「昨天」重叠成**悖论区**,同一时刻只能容纳一个「你」。想过去,就要学会与过去的自己错开时间;有些门,要由过去替你打开。

## 3. 场景结构与布局(18×12 格,等距 64×32)

```
          北 y1              出口(8,1)
     ── 北厅 x4..13, y1..3 ──  D2出口门(8,2)[S1∧S2]
     西储(封闭)          │回廊│   x3/x14 墙封北厅两侧
     x1..6,y4..7    y4墙(x4..7,x10..13) 回廊口x8..9
     x7墙(y4..7)   P1悖论区 x8..9, y5..7(紫)   x10墙(y4..7)
                        S2(8,6)在区内!
     南区 y8..10(横贯 x1..16):
     [记录区 x1..3,y8..10] 出生(2,9) 装置(3,8) C1(5,9) P2(6..7,8)
     G1(11,7)─东室 x12..15,y6..8:S1(14,7);口(11,8)
```

| 要素 | 格位 | 说明 |
| --- | --- | --- |
| 出生点 | (2,9) | 南区西段 |
| **初始记录区** | x1..3, y8..10(南区西段) | 记录只能从此开始(docs/17 §5.1);记录完成回到记录起点 |
| 时间记录装置 | (3,8) | 复用,T-03 |
| 教学凹室 P2 | (6,8)(7,8)(2 格) | **安全的悖论沙盒**:主路径之外,玩家在此亲手触发一次悖论(T-73 引导) |
| 能量核心 C1 | (5,9) | EnergyCore **持续型 toggle**(无 auto);**初始 ON**——供电型相位门 G1 由它驱动;L7 拨动双向可逆 |
| 相位门 G1 | (11,7) | 东室西墙唯一入口;**C1 ON=密封**(实体止步)/OFF=落下;回声恒可穿 |
| 东室 | x12..15, y6..8 | 墙围,仅 (11,7) 一个西入口;S1 所在 |
| 压力开关 S1 | (14,7) | 东室深处——**密封后玩家不可再入,只能由回声常踩** |
| **悖论区 P1** | x8..9, y5..7(6 格) | 中央回廊中段,**横贯整个回廊宽度,不可绕行**——南北唯一通道 |
| 压力开关 S2 | (8,6) | **P1 内部**——回声末帧停此即持续「占用」悖论区,玩家不可再入(E-77) |
| 安全门 D2(出口门) | (8,2) | 两条件聚合(归关卡层):S1 ∧ S2(当刻);**门正对出口 (8,1)**,回声路线不占门格 |
| 出口区 | (8,1) | 进入即通关 |
| 西储间 | x1..6, y4..7 | **整体封闭**(y7 行、x7 列、y4 行围合)——封死西侧绕行,保证 P1 是南北唯一通路 |

设计要点:
1. **回廊即瓶颈**:P1 横贯回廊宽度,玩家与回声的所有南北通行都必须「在场调度」——错峰是唯一解法;
2. **S2 放在 P1 内部**是本关谜题之眼:回声停进区内 = 玩家永远失去穿越权,迫使玩家**先穿区北上、再从北侧发射回声**(「先过去,再让过去发生」);误序(先发 E2 再穿区)可经 **X 删除**恢复——删除腾位由错误自然教出(E-77);
3. **东室 = 回声专属区**:C1 复拨 ON 后 G1 密封,S1 只能由回声常踩;玩家录制 E1 须趁 G1 落下时完成——「回声能去我不能去」的具象化;
4. 密封自查:北厅仅回廊口 (8,3)(9,3) 一个南入口;东室仅 (11,7) 一个西入口;西储间不可达。**格位按 32px 邻格口径推演;实现阶段以 probe_map 连通性探针 + 冒烟巡走复核,允许微调(先例:docs/16 v1.2/v1.3)**。

## 5. 操作流程(六步结构 + 时间预算)

| 步骤 | 玩家操作 | 反馈/完成条件 | 预算 |
| --- | --- | --- | --- |
| 1 观察 | 环视南区;东行撞 G1 → **阻挡 + T-71**;拨 C1 → 门落(可见因果) | 建立「相位门听核心的」模型 | 40—60s |
| 2 悖论初体验 | 凹室 T-73:录一段进凹室的路 → 回放 → 自己跟进去 → **闪白,回声碎裂 + T-72** | 亲手读懂「同场即碎」;安全失败(重发即可) | 40—80s |
| 3 记录并发射 E1 | 拨 C1 OFF → 从记录区起录 → 东行穿落下的 G1 → 停 S1 → R(回原位)→ **发射回声 1**(录一条发一条:记录只保留最近一条) | 回声 1 穿落下的门守 S1;C1 可复拨 ON(密封观赏:回声照样进,步骤 3 内完成) | 60—100s |
| 4 记录 E2 | 起录 → 穿**空的** P1 北行 → 停 S2(区内)→ R(回原位);**不发射** | 回声 2 路线就绪;此时玩家尚未注意到 S2 的「占用」后果 | 40—60s |
| 5 玩家穿区 + 北侧发射 | **玩家穿 P1 北上**(区内无回声,合法)→ 站北厅 **发射回声 2**(从北侧!)→ 回声穿区停 S2 → D2 开 | 核心技巧「先过去,再让过去发生」;误序者在此撞墙并学会 X 删除(E-77) | 60—120s |
| 6 通关 | (8,3) → D2 → 出口 | 冻结 + 结算 +「继续」 | 10—20s |

**误序恢复路径(必经的教学时刻)**:玩家在南侧先 fire E2(停 S2,区内)→ 再想穿区 → 被挡(P1 有回声在场)→ **X 删除 E2**(S2 释放)→ 北上后重新 fire E2。全程无需重置、无需重录。

替代解(满编 3):E3 录一条备用路线(如再穿区一次的短路线),用于误删 E2 后免重录重发——把「删除腾位」的恢复成本降到最低;标准解 2 回声已足够,**不存在 1 回声解**(S1、S2 须同时被非玩家占据)。

## 9. 边缘规则

| 编号 | 规则 |
| --- | --- |
| E-71 | 悖论判定 = **玩家在场 ∧ 任一回声在场**(同区重叠,先后无关):触发时区内**全部**回声消散;玩家无伤原地继续;触发瞬间区内闪白 |
| E-72 | 消散走 EchoManager 统一路径(`dissolve`):计数广播、残影与调试线清理同步;当刻起该回声退出 `echo_trigger` 组 |
| E-73 | **回声彼此同场不触发**(同为「过去」);回声生成点 = 记录起点,布局约束保证记录起点不在悖论区内(R5) |
| E-74 | 暂停中不判定(世界冻结,Area 信号不发);关卡重置清双清单复位视觉 |
| E-75 | 回声恒穿相位门(密封/落下皆然,逐帧赋位回放无视环境);G1 落下时玩家可穿(Blocker disabled);复封瞬间门内防夹(SecurityDoor 语义) |
| E-76 | C1 持续型 toggle 双向可逆,无自动复位;重置复位 C1 初始 ON 与 G1 密封态 |
| E-77 | 回声末帧停于 P1 内(S2)= 持续占用在场身份:玩家不可入区,直至 **X 删除该回声**(删除腾位是合法恢复路径,删除后 S2 释放、D2 重估) |
| E-78 | 发射时机判定:回声穿区期间玩家在区(哪怕半程/刚进)→ 当刻消散;玩家先在区、回声后进区 → 同样触发(双向) |
| E-79 | 出口门 D2 = S1 ∧ S2 当刻 AND(关卡层聚合);任一失活(删/消散)当刻重估、门关(走门本体防夹) |
