# 16 第六关关卡设计:失控区域(The Runaway Zone)

> 版本 v1.1 | 状态:已交付 | 日期 2026-11-07
> 章节规划:docs/13;模板:docs/12。回声上限 **3**;目标时长 **6—9 分钟(首通硬下限 6 分钟)**;难度 高。
> **无新场景机关**——章末综合关:复用干扰场/脉冲板语义要素/能量核心/时间锁,新增**序列门**(关卡层逻辑,docs/13 §5)。

## 1. 关卡基本信息

| 项目 | 设定 |
| --- | --- |
| 关卡名称 | 失控区域(The Runaway Zone) |
| 章节 | 第二章:时间异常(第 6 关,章节末关) |
| 回声上限 | 3(满编调度是标准解) |
| 定位 | 三区大地图 + 顺序约束 + 多回声错峰发射 + 10 秒冲刺(行动规划综合考) |
| 核心目标 | 玩家为三个区域各规划一条"给回声的路",按 **A→B→C** 的顺序激活序列机关,并在时间锁的 10 秒窗口内完成最终冲刺 |

## 2. 关卡剧情

越接近核心实验室,时间异常越严重。失控区域的自动化系统仍在按事故当天的规程运转——它们不承认"现在",只承认**顺序**:事故那天,值班员是先合 A 闸、再合 B 闸、最后按下时间锁的。想通过,就要把那天下午的行动,用三个过去的自己原样重演一遍。

## 3. 场景结构与布局(18×14 格,等距 64×32)

```
        北 y0            出口(9,0)
   A(2,3)      出口门(9,1)[四灯:A∧B∧C∧核心]     C(15,3)
   y1   (6,1)(6,2)缺口                (11,1..10)=F2
   ── F1 x=6,y3..12 ──  中区  ── F2 x=11,y1..10 ──
   F0 x=1..5,y7                F3 y=6,x=13..17
   (0列窄道)        B(8,3)           x12 窄道
   装置(3,9)                          核心(15,10)
        出生(2,11)                  (11,11)(11,12)南口
```

| 要素 | 格位 | 说明 |
| --- | --- | --- |
| 出生点 | (2,11) | 西区(x0..5)南端 |
| **初始记录区** | x0..5, y9..13(西区南段) | 记录只能从此开始(docs/13 §5.1);记录完成回到记录起点 |
| 时间记录装置 | (3,9) | 复用,T-03 |
| 干扰场 F0 | x=2..5, y=7(4 格) | 西区横带;**x1 列窄道**是回声 1 唯一北上通道(x0 是周界墙)——L4"绕行"技能的保持性考核 |
| 序列开关 A | (2,3) | PressureSwitch;序列 1,由回声 1 常踩 |
| 干扰场 F1 | x=6, y=3..12(10 格) | 西/中区隔离带;**北缺口 (6,1)(6,2)**——回声跨区唯一渡口 |
| 序列开关 B | (8,3) | PressureSwitch;序列 2,由回声 2 常踩(跨区路线) |
| 干扰场 F2 | x=11, y=1..10(10 格) | 中/东区隔离带;**南口 (11,11)(11,12)** |
| 干扰场 F3 | y=6, x=13..17(5 格) | 东区内部横带;**x12 窄道**为东区南北唯一通路(冲刺与 R3 路线共用) |
| 能量核心 | (15,10) | EnergyCore **持续型**(auto_off=0);E 交互,门第四条件;**由玩家亲自拨动**(持续型核心若走"录制中拨动+回声重放再拨动"会互相抵消——E-55 历史重演语义;回声途中拨核能力保留,见 E-64) |
| 序列开关 C(时间锁) | (15,3) | TimeLockSwitch 基础语义:踩上激活 + 10s 倒计时;序列 3 |
| 出口门 | (9,2) | 四条件聚合(归关卡层):A ∧ B ∧ C ∧ 核心(当刻);**门置 (9,2) 让北走廊 y1 畅通**——y1 是回声跨区唯一北通道,不得被门占用 |
| 出口区 | (9,0) | 进入即通关 |

设计要点:
1. **干扰场割裂 = "限制条件下的协作"**(docx 主题):回声可跨区但必须走指定渡口,路线长且贪短即碎——每条回声路线都被迫"绕行",玩家在录之前必须先在脑中走一遍;
2. **三条路线三种形状**:A 路 = x0 窄道长直线(~14 格,9—11s);B 路 = 北渡口跨区折南(~15 格,10—12s);R3 = 东区内"穿 x12 窄道 → 踩 C"的窄道长路线(~17 格,11—13s,末帧停 C);
3. **行动规划**:三条记录的发射顺序与间隔决定序列合法性与窗口重叠——A/B 到位时序天然错开(回声 2 稍后发射),C 窗口开启时 A∧B 已就位;玩家在 C 的 10 秒窗内经 x12 窄道冲向出口门(~12 格,约 8s);
4. 乱序在第一步就会发生(玩家本能地先冲 B)→ T-62 的教学时机天然出现。

## 4. 机关与交互对象

| 对象 | 规则 | 反馈 |
| --- | --- | --- |
| PressureSwitch A/B ×2 | 复用现有契约;**参与序列**(见下) | 激活变黄;对应指示灯 |
| **序列门(关卡层逻辑,新)** | 每次开关**新激活**时检查:激活第 i 号时,第 1..i−1 号必须全部处于激活态;**乱序 = 该次激活无效**(开关不亮)+ 底座闪红 0.5s + T-62;前序保持(温和版,见决策记录);最终门 = A ∧ B ∧ C ∧ 核心(当刻 AND) | 四指示灯;乱序闪红反馈 |
| TimeLockSwitch C | 复用 L3 场景,基础语义(无 arm 接线):踩上激活 + 10s 倒计时,到期自动释放;最后 3s 闪烁(T-16/T-17 复用) | 同 L3 |
| EnergyCore | 复用 L5 契约,持续型;回声途中拨动与玩家同效 | ON 亮黄光环 |
| InterferenceField F0—F3 | 复用 L4 契约(消散) | 暗红脉动 |
| SecurityDoor / TimeRecorderDevice / ExitArea | 复用 | — |

**决策记录(序列惩罚强度)**:选择**温和版**(乱序无效 + 提示,前序保持)——与 NFR-06"仅凭提示即可通关"的友好度基调一致;硬核版(乱序触发全场复位脉冲,呼应"失控"主题)列为备选,若 playtest 反馈难度不足再启用,已在实现清单外备注。

## 5. 操作流程(六步结构 + 时间预算)

| 步骤 | 玩家操作 | 反馈/完成条件 | 预算 |
| --- | --- | --- | --- |
| 1 观察 | 出生环视;北上试踩 B(A 未激活)→ **无效 + 闪红 + T-62** | 乱序教学的天然时刻;理解"只认顺序" | 40—60s |
| 2 发现 | 靠近 C(T-61 时间锁提示);看出口门四灯 | 建立"顺序 + 四灯 + 时间窗"目标模型 | 20—40s |
| 3 记录 A 路 | 绕 F0(x0 窄道)北上停 A | 回声 1 常踩 A(序列 1) | 40—60s |
| 4 记录 B 路 | 北渡口 (6,1) 跨区 → 折南停 B | 回声 2 常踩 B(序列 2;须在 A 就位后**激活**) | 40—60s |
| 5 记录 R3 | 玩家自由穿场走到东区 → 录"x12 窄道北上 → 踩 C(末帧)";随后**亲自拨核心 ON** | 回声 3:末段踩 C 触发 10s 窗;核心持续 ON(门第四条件) | 60—90s |
| 6 编排冲刺 | 依次发射三条回声(录一条发一条;每段等前序就位)→ C 窗开启 → 玩家经 x12 窄道冲门 | 四灯全亮 → 门开 → 10s 内跨入出口 | 90—150s |
| 7 通关 | 进入出口区 | 冻结 + 结算 +「—— 第二章 完 ——」 | 10—20s |

替代解(高手,2 回声):回声只守 A/B,**玩家亲自**踩 C 触发 10s 窗 → 经 x12 窄道冲刺(~10 格,6—7s)——省一条长记录,把窗口压力换成玩家跑位压力;核心仍由玩家提前拨 ON。

## 9. 边缘规则

| 编号 | 规则 |
| --- | --- |
| E-61 | 序列检查仅发生在「新激活事件」:激活第 i 号时第 1..i−1 号须全部激活;乱序 = 无效 + 闪红 0.5s + T-62(once);前序保持不清 |
| E-62 | 已合法激活的开关中途失活(回声被删/消散):门条件当刻重估;该开关再次激活仍按序列检查(前序在则合法) |
| E-63 | 时间锁 C 沿用基础语义(E-31/32 复用):到期自动释放、回声踩住不延长、重踩须先离开再进入 |
| E-64 | 核心不参与序列(门第四条件独立);回声途中拨核与玩家同效(E-53 继承);核心 ON 持续,不自动熄灭 |
| E-65 | 消散与序列:回声路线贪短穿场 → 消散 → 该区缺员,对应开关失活、门重估(E-42/43 继承) |
| E-66 | 重置:序列状态/闪红计时/全部机关(含核心与屏障类)/回声/记录/残影全量复位;时间锁重新武装(E-58 继承) |
| E-67 | 出口门四条件聚合,到期/失活关门走门本体防夹 |
| E-68 | 三条回声可任意顺序发射、同时运行;序列合法性由「激活时刻」判定,与发射时刻无关(发射时序只影响到达时刻与窗口重叠) |
| E-69 | 冲刺失败(C 窗错过):门随窗口关闭;重新触发 C 须先离开再进入;核心仍 ON,无需重拨 |
