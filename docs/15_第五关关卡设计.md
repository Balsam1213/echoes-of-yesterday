# 15 第五关关卡设计:重复的实验(The Repeated Experiment)

> 版本 v1.1 | 状态:已交付 | 日期 2026-11-07
> 章节规划:docs/13;模板:docs/12。回声上限 **3**;目标时长 **5—7 分钟(首通硬下限 5 分钟)**;难度 中高。
> 新机关首发:**能量核心**(E 键交互,**记录 events 字段首次启用**)、**联动屏障**(核心驱动的环境变化)。

## 1. 关卡基本信息

| 项目 | 设定 |
| --- | --- |
| 关卡名称 | 重复的实验(The Repeated Experiment) |
| 章节 | 第二章:时间异常(第 5 关) |
| 回声上限 | 3(标准解用 2,替代解用 1) |
| 定位 | E 键交互入门 + 回声途中交互 + 多回声时序编排 |
| 核心目标 | 玩家学会"按 E 会被记录、回声会替你按";用两条回声的**到达时刻编排**满足双条件门;发现"影子不认识今天的墙" |

## 2. 关卡剧情

机房日志停在"第 41 次协同试验"。实验核心一旦启动,八秒后必然熄灭——这台设备早已损坏,却仍被反复启动。日志的最后一行是新的笔迹:"一个人做不完这个实验。"玩家要做的,是让**过去的自己**在同一张地图上同时按下两处按钮:一个过去的你守住开关,另一个过去的你在八秒的窗口里拨动核心。

## 3. 场景结构与布局(16×12 格,等距 64×32)

```
        北 y0              出口 (13,0)
   A(2,2)            出口门 (13,1)[两灯:A∧核心2]
   y1   [桥(8,1)]─┐
   分隔墙 x=8(全高,唯一通路=北桥)   
   F1 竖带 x=11,y=3..10(缺口 y=1..2 北段)
   核心1(3,5)   │        核心2(13,8)
   装置(4,7)    │        机房
        出生(2,9)│
```

| 要素 | 格位 | 说明 |
| --- | --- | --- |
| 出生点 | (2,9) | 前厅西南;前厅 = x0..7 |
| **初始记录区** | x0..6, y1..11(前厅) | 记录只能从此开始(docs/13 §5.1);记录完成回到记录起点 |
| 时间记录装置 | (4,7) | 复用,T-03 |
| 能量核心 1 | (3,5) | E 交互 toggle;**持续型**(auto_off=0);驱动北桥:ON=降(通行)、OFF=升(阻挡) |
| 北桥(ToggleBarrier) | (8,1) | 前厅↔机房**唯一通路**;分隔墙 x=8 全高;初始升起 |
| 压力开关 A | (2,2) | 前厅西北;出口门条件之一,由回声 1 常踩 |
| 干扰场 F1 | x=11, y=3..10(8 格) | 纵贯机房;**缺口 = 北段 (11,1)(11,2)**——回声去核心 2 必须绕北缺口,贪短横穿即碎 |
| 能量核心 2 | (13,8) | E 交互 toggle;**8 秒自动失效型**(auto_off=8):ON 后 8 秒强制回 OFF——「重复的实验」主题来源 |
| 出口门 | (13,1) | 两条件聚合(归关卡层):A 激活 ∧ 核心 2 ON(当刻) |
| 出口区 | (13,0) | 进入即通关 |

设计要点:
1. **核心 2 的 8 秒窗制造"单人不可行"**:从核心 2 (13,8) 到门 (13,1) 虽只 7 格,但要先保 A 常亮——玩家本人踩住 A 就无法拨核,先拨核再跑 A 又超过 8s 折返距离 → 必须由回声分担;
2. **双回声时序编排是本关动脑核心**:R1(踩 A,~12—14s 到位)与 R2(途中拨核,~11—13s 行程、E 发生于约 8s 处)的**发射间隔**决定 A 与核心 2 的窗口是否重叠(同发擦肩而过 = 教学样例;错峰 = 解)。存在多种可行编排(先 1 后 2 / 先 2 后 1 立即跟发),玩家可探索;
3. **影子穿墙**作为可发现规则:把核心 1 拨 OFF(桥升起)后,回声 1 仍会沿记录路线"穿过"升起的桥踩住 A(T-52)——回声不与当下环境解算的总纲在此可见化,为 L6 的高阶用法铺垫。

## 4. 机关与交互对象

| 对象 | 规则 | 反馈 |
| --- | --- | --- |
| **EnergyCore(新,×2)** | `echo_trigger` 实体在 proximity 内按 E → toggle;`core_toggled(on)` 信号;`@export auto_off_seconds`(核心 1=0 持续,核心 2=8 到期自动回 OFF);**玩家与回声触发完全同效**(E-53) | ON 亮黄光环 / OFF 暗灰;核心 2 剩余 ≤3s 快闪(复用时间锁闪烁节奏) |
| **ToggleBarrier(新,北桥)** | `set_raised(bool)`:升起=脚印菱形碰撞阻挡、降下=通行;由关卡层订阅 `core_toggled` 驱动;**升起前检测桥格内 echo_trigger 实体,有则延迟至清空**(复用门防夹模式,E-59) | 桥板升降位移动画 |
| PressureSwitch A ×1 | 复用现有契约 | 同前 |
| InterferenceField(F1) | 复用 L4 契约(消散) | 同 L4 |
| SecurityDoor(出口门) | 两条件 AND(归关卡层):A ∧ 核心 2 ON(当刻评估) | 两指示灯 |
| TimeRecorderDevice / ExitArea | 复用 | — |

**交互事件链(events 字段首次启用,原始方案「记录有效交互事件」的落地)**:

1. **采集**:PlayerController 按 E 且 proximity 内有核心 → 核心真实 toggle(录制即真实行动,E-57)+ PlayerController 发 `interacted(target)`;TimeRecorder 在**当前采样帧**的 `events` 追加 `{type:"interact", target: NodePath}`;
2. **重放**:EchoController 回放到含 `events` 的帧 → 按相对关卡根的 target_path 取节点 → 调用其 `toggle()`;节点缺失则跳过并 `push_warning`,不中断回放;
3. **一致性**:同帧、同目标、同效果——与 TC-23 回放一致性同源(NFR-02);回放数据不因屏障当下状态修正(见 E-51)。

## 5. 操作流程(六步结构 + 时间预算)

| 步骤 | 玩家操作 | 反馈/完成条件 | 预算 |
| --- | --- | --- | --- |
| 1 观察 | 前厅环视;靠近核心 1(T-51)→ 按 E → 桥降下 | 学会"E = 交互";看到屏障与核心的联动 | 30—40s |
| 2 发现 | 过桥进机房;靠近核心 2 按 E(T-53:8 秒窗)→ 看它自动熄灭;踩 A 试灯 | 建立"核心 2 八秒必灭"与"门 = 两灯"认知 | 30—50s |
| 3 记录 R1 | 从机房西侧录"过桥回前厅 → 北上 → 停 A"(此刻桥降,录得通) | 回声 1 待发(约 12—14s 到位) | 30—50s |
| 4 记录 R2 | 录"北上 → 绕 F1 北缺口 → 南下 → 按 E 拨核心 2 → 折返"(**录制中按 E 真实生效**,核心亮 8 秒 = 预演) | 回声 2 待发(E 发生于约 8s 处) | 40—60s |
| 5 时序编排 | 发射 R1 与 R2,调整**发射间隔**使 A(回声 1 到位后)与核心 2 窗口重叠 → 门开 → 玩家(候在门边)跨入 | 同发擦肩 = 教学样例;错峰成功 = 门开 | 90—150s |
| 6 通关 | 进入出口区 | 冻结 + 结算 +「第 5 关 完成」 | 10—20s |

替代解(高手,单回声):回声 1 踩 A;**玩家亲自**走 R2 路线拨核(8s 窗)→ 从核心 2 (13,8) 全速冲到门 (13,1)(7 格 ≈ 4s)跨入——省一条记录,把时序压力换成跑位压力。

## 9. 边缘规则

| 编号 | 规则 |
| --- | --- |
| E-51 | **回声不与当下环境解算(总纲)**:回声按记录位置逐帧赋位,可穿过升起的桥/屏障;唯一以"当下"伤害回声的是干扰场;禁止用当下碰撞修正回声轨迹 |
| E-52 | events 重放确定性:同帧同目标同效果;同一记录多次回放结果一致(NFR-02,TC-23 同源口径) |
| E-53 | 回声拨核与玩家拨核完全同效(`core_toggled` 同源),关卡层不区分触发者(机关契约:同等触发者) |
| E-54 | 核心 2 到期自动回 OFF → 门条件当刻重估(AND 关门,防夹照常);倒计时由 auto_off 计时驱动,与回声是否仍站在 proximity 无关 |
| E-55 | 重复发射同一记录 = 历史重演:toggle 随回放次数翻转,auto_off 计时随每次拨动重启——玩家可预期,非缺陷 |
| E-56 | 录制中按 E 但 proximity 内无核心 → 不写 events、无效果(空挥) |
| E-57 | **录制中的交互即时生效**(录制 = 真实行动):玩家录 R2 按 E 时核心 2 真实 ON 并开始 8s 倒计时(教学预演);回声重演时再次生效 |
| E-58 | 重置:核心(含 auto_off 计时)/屏障(复位升起)/门/回声/记录/残影全量复位;教学标志重武装 |
| E-59 | 屏障升起前检测桥格内 echo_trigger 实体,有则延迟至清空(防夹);屏障状态变化不影响已存在回声的既定轨迹(E-51 推论) |
