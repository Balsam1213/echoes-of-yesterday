# 14 第四关关卡设计:时间干扰(Interference)

> 版本 v1.1 | 状态:已交付 | 日期 2026-11-07
> 章节规划:docs/13;模板:docs/12。回声上限 **3**;目标时长 **4—6 分钟(首通硬下限 4 分钟)**;难度 中高。
> 新机关首发:**时间干扰装置**(回声进入即消散)、**脉冲板**(瞬踩 0.5 秒)。

## 1. 关卡基本信息

| 项目 | 设定 |
| --- | --- |
| 关卡名称 | 时间干扰(Interference) |
| 章节 | 第二章:时间异常(第 4 关) |
| 回声上限 | 3(满编;替代解使用 3 回声编队) |
| 定位 | 大地图多阶段 + 干扰路线规划 + 瞬时踩踏/发射时机入门 |
| 核心目标 | 玩家学会"回声的路线会被干扰改写"并为回声规划绕行;用「瞬时踩踏 + 同振窗口」完成回声与本人的时序协作 |

## 2. 关卡剧情

时间异常不只发生在装置里。第二区的空气中弥漫着肉眼可见的暗红干扰——那些半透明的影子走到一半,就会当场碎裂。实验记录残片写着:"影子只能在它被记录时的那条路上行走。"玩家必须为过去的自己规划一条**干扰碰不到的路**,再让两块只认"经过"的脉冲板,在同一瞬间接通。

## 3. 场景结构与布局(16×12 格,等距 64×32)

```
        北 y0                       出口 (13,0)
   A(3,2)            P(13,2) ←─ 出口门 (13,1)[三灯:A∧B∧P 同振]
   y4 ────────────────────────────────────────
   y5  ■■■■■■■■■■■■■ 干扰带 F1 ── 缺口(x12..15)
   y6        ■F2■
   y7        ■F2■  B(10,7)  ■F2■
   y8        ■F2■  (南口10,8) ■F2■
   y9
   y10  出生(2,10)
   y11       装置(3,8)在出生北上途经侧
```

| 要素 | 格位 | 说明 |
| --- | --- | --- |
| 出生点 | (2,10) | 西南区;可见出生区、F1 暗红带与远处北墙,出口细节需走近发现 |
| **初始记录区** | x0..3, y9..11 | 记录只能从此开始(docs/13 §5.1);记录完成回到记录起点 |
| 时间记录装置 | (3,8) | 出生北上必经侧,proximity 触发 T-03(复用) |
| 干扰带 F1 | x=0..11, y=5(12 格) | 横贯西中部;**缺口 = 东段 x12..15**——回声与玩家给回声规划的路线的唯一北渡口 |
| 干扰场 F2(U 形) | (9,6)(10,6)(11,6)(9,7)(11,7)(9,8)(11,8)(7 格) | 围住 B;**唯一南口 (10,8)**,北缘 (10,6) 封死——回声须"南进南出",贪短即碎 |
| 压力开关 A | (3,2) | 西北角;出口门 AND 条件之一,由回声 1 常踩 |
| 脉冲板 B | (10,7) | U 形场内;回声 2 路线"经过但不驻守"(驻守也无效) |
| 脉冲板 P | (13,2) | 出口门正南邻格;玩家本人踩踏对齐 |
| 出口门 | (13,1) | 三灯:A ∧ 同振(B∧P);同振触发后门维持开启 1.5 秒 |
| 出口区 | (13,0) | 进入即通关 |

设计要点:
1. **玩家全图自由**(干扰只伤回声),所有约束施加在"给回声规划的路线"上——这是本章"回声运动过程即谜题"的第一次完整呈现;
2. 两条回声路线刻意不同形:A 路 = 东行绕缺口再折西的 **~27 格长路线(约 14—18 秒)**,B 路 = 南口进出的 **~14 格短路线(约 8—10 秒)**;两条路线都存在"贪短必碎"的可见失败样例(北上直穿 F1 / 从 U 形北缘进 F2);
3. 同振谜题的时序深度来自**发射时机**:回声 2 每次发射都是一次对齐机会,玩家借助轨迹残影(§4 轨迹残影)测量回声过 B 的时刻,再掐点踩上 P。

## 4. 机关与交互对象

| 对象 | 规则 | 反馈 |
| --- | --- | --- |
| PressureSwitch A ×1 | 复用现有契约 | 激活变黄下沉;对应指示灯 |
| **PulsePad(新,B/P ×2)** | 任何 `echo_trigger` 实体进入即激活,**0.5 秒后强制释放**;停留无效、不可延长、无冷却(见 E-46) | **青色系**(与压力开关的灰/黄区分):待机青灰、激活亮青 #45D9F2 快闪;对应指示灯随激活点亮 |
| **InterferenceField(新,F1/F2)** | 恒定危害区(非开关):**回声回放位置进入判定圈即消散**(格心圆 r8,等同删除,见 E-41/42);玩家踏入只触发预警不受伤(E-45) | 暗红 #D95D5D 半透明菱形覆格(±12,格心对齐)、缓慢脉动;消散时回声青色碎裂闪烁后消失 |
| SecurityDoor(出口门) | 三条件聚合(归关卡层):A 激活 ∧ 同振(B∧P 同帧激活)→ 开门并**维持 1.5 秒**,到期关门(防夹生效,E-47) | 三指示灯:A 常亮态、B/P 随各自 0.5s 激活闪烁;门体红/绿 |
| TimeRecorderDevice | 复用(proximity T-03) | — |
| ExitArea | 仅玩家触发 | 通关 |

**轨迹残影**:本关起回放结束后保留淡色轨迹线(透明度 ~25%,删除/消散/重置时清理)——同振谜题的"测量回声时刻"依赖它,是玩法支撑而非调试工具。

**干扰场关键规则(与第一章机关的本质区别)**:干扰场没有"激活"概念,它恒定存在;机关契约照常实现(`mechanism` 组 / `force_reset()`),但它的作用是**改写回声的可行路线空间**。必须在首次靠近(T-41)与首次消散(T-42)两个时刻教会玩家。

## 5. 操作流程(六步结构 + 时间预算)

| 步骤 | 玩家操作 | 反馈/完成条件 | 预算 |
| --- | --- | --- | --- |
| 1 观察 | 出生环视,东行发现干扰带(F1 变红、T-41)、装置(T-03) | 建立"红色区域=回声禁区"直觉 | 20—30s |
| 2 发现 | 北上试踩 A(A 灯亮、离开即灭);走到出口门看到三灯 | 建立"门 = 三灯全亮"认知;发现 B/P 无法常踩(脉冲板 0.5s,踩住也弹起,T-43) | 30—50s |
| 3 记录 A 路 | 先录贪短直路线(北上穿 F1)→ **回声消散的可见失败**(T-42)→ 重录"东行绕缺口 → 折西 → 停 A" | 回声 1 常踩 A,A 灯常亮 | 60—90s |
| 4 记录 B 路 | 录"南下东行 → 北上进 U 形南口 → 瞬踩 B → 折返" | 回声 2 全程重演,B 灯在 t≈6—8s 闪 0.5s | 40—60s |
| 5 组合同振 | 发射回声 2 → 借残影/目测预估过 B 时刻 → 掐点踩上 P → B∧P 同帧 → 门开 1.5s → 跨门冲入出口 | 核心试错环节;错峰即门不开(T-44 首败提示) | 90—150s |
| 6 通关 | 进入出口区 | 冻结 + 结算 + 存档 +「第 4 关 完成」 | 10—20s |

替代解(高手,3 回声编队):回声 2 过 B 与**回声 3 过 P** 对齐(两条记录分别经过 B/P,错峰发射使二者同帧),玩家本人自由身在门前跨入——省去踩 P 的跑位,代价是双回声编队的发射时序更难调。

## 9. 边缘规则

| 编号 | 规则 |
| --- | --- |
| E-41 | 回声消散于**回放位置进入干扰判定圈的当帧**;判定圈 = 格心圆 r8(视觉=全格暗红覆格,与判定圈分离——车道最小间隙 ~28.6px,贴行绝不误伤,穿越格心必触发);末帧停留不豁免(记录末点在场内 = 播完即碎) |
| E-42 | 消散 = EchoManager 正式注销(计数 −1、`echo_deleted` 广播、残影清理);与 X 删除同路径,仅表现不同 |
| E-43 | 消散回声已触发的机关**不回滚**:压力/脉冲板按"离开"自然释放,已拨核心不回拨(为 L5 铺垫) |
| E-44 | 记录起点在干扰场内 → 回声生成当帧即消散(消耗一次上限,T-41 提示) |
| E-45 | 干扰只作用于 `echo` 组:玩家、机关、门体均不受影响;回声之间互不检测 |
| E-46 | 脉冲板 0.5s 固定窗:持续踩住不延长;激活期内重复进入不刷新;两次触发之间无冷却 |
| E-47 | 同振维持 1.5s 到期关门走门本体防夹规则;玩家在门洞内到期 → 保持开启待清空;重开需重新同振 |
| E-48 | 重置四步全量复位 + 同振计时器取消 + 脉冲板计时清零;干扰场无状态;残影全部清理 |
| E-49 | 回声在 B/P 上被消散(路线误穿 U 形侧缘等)→ 同振条件当帧失效,门不开 |
