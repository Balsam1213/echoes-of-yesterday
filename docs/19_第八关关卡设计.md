# 19 第八关关卡设计:昨日回声(The Echo of Yesterday)

> 版本 v1.0 | 状态:评审中 | 日期 2026-11-07
> 章节规划:docs/17;模板:docs/16。回声上限 **3**;目标时长 **7—11 分钟(首通硬下限 7 分钟)**;难度 高。
> **章末综合关**:无新场景机关——大悖论区在场调度 + 联动相位门断电窗(关卡层计时)+ 三重条件门;真相反转在通关文案揭晓。

## 2. 关卡剧情

时间异常的震中就在前面。核心实验室的主厅中央,空间与「昨天」大面积重叠成**悖论之海**——海心的异常核心维持着全舱的相位封锁。核心舱里立着最巨大的记录装置,它与走廊尽头那台小小的记录仪是同一种造物。舱内的记录仪上,最早的一段记录,日期是**昨天**。

      [记录区 x1..5,y9..12] 出生(2,11) 装置(3,10)        东南块封闭

| 相位门 G1 | (13,2) | 核心舱西墙唯一入口;**C1 ON=密封 / OFF(断电窗)=落下**;回声恒可穿 |

| 安全门 D2(出口门) | (15,2) | 三条件聚合(归关卡层):**S1 ∧ S2 ∧ TL 激活**(当刻);**门正对出口 (15,1)** |
| 出口区 | (15,1) | 核心舱内东北角,进入即通关 |

| 东南块 | x13..16, y5..8 | 封闭(墙围),维持「海 + 舱」的极简结构 |

设计要点:
1. **拨核必须进区**(C1 在 P1 内)是本关在场调度之眼:玩家与两条回声共用海面,必须编排「谁在场」的时间表;
2. **回声路线均不过 G1、不碰 C1**(E-87):录制无窗口压力,断电窗只压玩家的冲刺——「回声的行程表就是玩家的时刻表」用于发射编排,窗口张力留给终局;
3. **双 10s 窗贴合并行**:拨核(断电窗起)→ 穿海北缘 → 横廊踩 TL(第二窗起)→ 过 G1 → D2 → 出口 ≈ 12—13 格 ≈ 8—9s,两窗裕量 1—2s,最后 3s TL 闪烁——终局紧张感的来源;
4. **冲刺失败恢复顺畅**(E-86):超窗复电复封后,回声仍在 parks,玩家原地重试(再进区拨核),无需重置重录;
5. 门位铁律自查:D2 (15,2) 正对出口 (15,1);G1 是舱体唯一入口且不占回声必经渡口(回声路线不过 G1);回声 parks 均在 P1 之外(S1/S2 在横廊)。**格位按 32px 邻格口径推演;实现阶段以 probe_map + 冒烟巡走复核连通性,允许微调(先例:docs/16 v1.2/v1.3)**。

## 5. 操作流程(七步结构 + 时间预算)

| 步骤 | 玩家操作 | 反馈/完成条件 | 预算 |
| --- | --- | --- | --- |
| 1 观察 | 环视南区;西窄道北上**侦察支路**(看清核心舱、密封的 G1、TL、S1/S2 全貌)→ 折返 | 建立「海 + 舱 + 双窗」目标模型;撞 G1 → T-81 | 60—90s |
| 2 试探 | 从南区探入 P1 边缘(无回声,合法)→ 看海心 C1 → T-82 | 读懂「拨核必须进区」 | 30—60s |
| 3 记录 E-A | 起录 → 穿海(南缘→区中→北缘)→ 横廊东行 → 停 S1 → R(回原位) | 长路线 ~18—19 格(13—15s);录制期无窗口压力 | 50—80s |
| 4 记录 E-B | 起录 → 穿海 → (6,1) 停 S2 → R(回原位) | 路线 ~13—14 格(10—11s) | 40—70s |
| 5 发射编排 | fire E-A(**玩家在南廊等待,不入区**)→ 出区 parks S1 → fire E-B → parks S2;两回声穿海期间玩家不得入区 | 错峰在场调度;误发即消散的可见失败(E-88) | 60—120s |
| 6 断电冲刺 | 确认海面无回声 → 进区 → 拨 C1(**10s 断电窗起**)→ 穿海北缘 → 横廊踩 TL(**10s 窗起**)→ 东行过落下的 G1 → D2 → 出口 | 双窗贴合并行,时距 8—9s / 裕量 1—2s;失败恢复见 E-86 | 60—180s(试错 2—4 次) |
| 7 通关 | 进入出口区 | 冻结 + 结算 + **「—— 第三章 完 ——」**(T-83 真相揭晓) | 10—20s |

替代解(满编 3):E3 录一条「横廊东段待命」短路线,冲刺失败后免重录快速恢复 parks 阵型;或将 E-B 改为「玩家亲自北上后从北侧发射」(L7 技巧复用)缩短首次穿海等待——标准解 2 回声已足够,**不存在 1 回声解**(S1、S2 须同时被非玩家占据,玩家拨核冲门无法兼踩)。
