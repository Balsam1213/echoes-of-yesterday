## 2. 范围与质量基准

## 5. 生产流程

严格按 [07](07_工作说明与开发流程.md) 执行:
**开工**(§3.1):读 devlog 最新条目 → 查 issues 未关闭 S1/S2 → 从 06 领任务、明确 DoD。
**收工**(§3.2):devlog 必写 → changelog 按需 → issues 登记 → `git commit`(信息对应任务号)。
**纪律**:未自测不提交;一条任务至少一次提交。

## 6. 质量门

1. 每个里程碑以 [06 §2](06_执行计划与任务分解.md) 的 DoD 为唯一通过标准;未满足则停留在当前里程碑,禁止进入下一个。
2. **M3 为核心质量门**:轨迹一致性(R1)与核心闭环用例(TC-11~13)不过,后续所有工作暂停,先解决问题。
3. M5 全量回归(08 全部用例)必须整体执行一遍,不允许抽样。

### 9.2 Godot 安装指引(人工,约 10 分钟)

1. 打开 [godotengine.org/download](https://godotengine.org/download) → Windows → 下载 **Godot Engine** 标准版 ZIP;
2. 解压到任意目录(如 `D:\Tools\Godot\`),运行其中的 `Godot_v4.x-stable_win64.exe`(免安装,单文件引擎);
3. (可选)发送桌面快捷方式;以后双击它 → Import 打开本工程。

### 9.3 M0 剩余人工项(装好 Godot 后逐项打勾)

- ☐ Godot 编辑器 → Import → 选择 `EchoesOfYesterday/project.godot` 打开工程;
- ☐ 项目设置 → 显示:视口 640×360、窗口覆盖 1280×720、拉伸 canvas_items/keep;
- ☐ 项目设置 → 输入映射:10 个 action 与 03 §5 一致(移动四向/interact/record_toggle/play_echo/reset_room/delete_echo/pause);
- ☐ 项目设置 → 层名称:2D 物理层 1=world、2=player、3=echo、4=trigger;
- ☐ VS Code 安装 godot-tools 扩展;Godot 编辑器设置 → 文本编辑器 → 外部编辑器指向 VS Code;
- ☐ F5 试运行:会提示「未设置主场景」——**属正常**(M1 建出 Level_01 后再设);
- ☐ 全部通过后:本表打勾 → 09 §4 将 M0 状态改 ✅ → 提交。

### 9.4 已由配置文件完成的 M0 项(2026-11-04)
