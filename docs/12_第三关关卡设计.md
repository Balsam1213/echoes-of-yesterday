# 12 第三关关卡设计:不同的路径(Three Routes)

> 版本 v1.0 | 状态:已实现(待人工验收) | 日期 2026-11-05
> 章节规划:docs/10;模板:docs/05。回声上限 **3**;目标时长 **4—6 分钟**;难度 中。
> 新机关首发:**时间锁**(倒计时开关,docs/10 §4)。

## 1. 关卡基本信息

| 项目 | 设定 |
| --- | --- |
| 关卡名称 | 不同的路径(Three Routes) |
| 章节 | 第一章:苏醒(第 3 关,章节末关) |
| 回声上限 | 3(本关开放至满额) |
| 定位 | 多路线记录 + 三条件并发 + 时间窗冲刺 |
| 核心目标 | 玩家为三条不同形状的路线各录制一条回声,并在时间锁的 10 秒窗口内完成最终冲刺 |

## 2. 关卡剧情

实验区中枢大厅的三面墙后各有一台稳压开关,而大门的锁需要三台同时供电。更糟的是,北翼的开关是一台**时间锁**——供电只能维持十秒。玩家必须让三个自己各守一条路径,再在时间的缝隙里穿过大门。

## 3. 场景结构与布局(14×10 格,等距 64×32)

```
        北:出口 (7,0) ← 出口门 (7,1) [三灯]
   时间锁C (5,2)                 B路线(东翼 L 形)→ 开关B (12,4)
              ┌── 中央枢纽 ──┐
   A路线(西翼直路)→ 开关A (2,6)
                   出生点 (7,8)
```

| 要素 | 格位 | 路线特征(自出生点) |
| --- | --- | --- |
| 出生点 | (7,8) | 中央枢纽南端,三翼尽收眼底 |
| 开关 A(西) | (2,6) | **直线短途**(约 5 格):最容易的一条,教学余量 |
| 开关 B(东) | (12,4) | **L 形绕行**:东行被墙阻,需先北后东(约 8 格) |
| 时间锁 C(北西) | (5,2) | **折返长廊**(约 7 格)且**离出口门最近**——冲刺起点 |
| 出口门 | (7,1) | 三灯 AND:A+B+C 全激活才开启 |
| 出口区 | (7,0) | 门后一格,进入即通关 |

设计要点:三条路线长度与形状刻意不同(直/L/折返)——录制顺序与走位效率成为时间安排的核心;时间锁 C 与出口门相邻,使"最后一个回声踩 C + 本人冲刺"成为标准解,而"亲自踩 C 再冲刺"是高手替代解(两解并存,见 §9)。

## 4. 机关与交互对象

| 对象 | 规则 | 反馈 |
| --- | --- | --- |
| PressureSwitch A/B ×2 | 复用现有契约 | 激活变黄下沉;对应指示灯 |
| **TimeLockSwitch(新)** | 踩上即激活并启动 **10s 倒计时**;到期**无论是否被踩住都自动释放**;重新激活需先离开再进入;最后 3 秒闪烁 | 激活变黄;倒计时最后 3 秒闪烁;HUD「时间锁启动:剩余 10 秒」 |
| SecurityDoor | AND 聚合:A+B+C 全激活才开(Level03Manager 聚合) | **三指示灯**(灯由关卡层驱动,门只收最终布尔) |
| 出口区 | 仅玩家触发 | 通关 |

**时间锁关键规则(与压力开关的本质区别)**:回声站在 C 上**并不能**让它一直激活——到期照常释放。这是时间压力的来源,必须在首次踩踏时通过提示与视觉教会玩家。

## 5. 操作流程(用户六步结构)

| 步骤 | 玩家操作 | 反馈/完成条件 |
| --- | --- | --- |
| 1 观察 | 出生环视 | 三翼、三灯门尽收眼底 |
| 2 发现 | 依次踩 A、B(灯亮)、C(灯亮+倒计时→10 秒后熄灭) | 触发 T-15「时间锁只维持十秒。」——教学核心时刻 |
| 3 记录 A 路 | 西行录制 → Space | 回声 1 踩住 A,灯 1 常亮 |
| 4 记录 B 路 | L 形路线录制 → Space | 回声 2 踩住 B,灯 2 常亮(两灯齐) |
| 5 组合 | 走到 C,录制"踩上 C"→ Space → **10 秒窗口开启** | 灯 3 亮→门开;玩家全速经门冲入出口 |
| 6 通关 | 进入出口区 | 冻结+结算:LEVEL_COMPLETED + 存档 +「第一章 完」 |

替代解(高手):只用 2 个回声踩 A/B,本人亲自踩 C 后立即冲刺——省一次录制,但要背着倒计时跑完全程。

## 6. 状态设计

| 状态 | A | B | C | 门 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 初始 | 关 | 关 | 关 | 关 | — |
| 两灯 | 开 | 开 | 关 | 关 | 回声 1/2 就位,等待时间窗 |
| 窗口开启 | 开 | 开 | 开(倒计时) | **开** | 冲刺阶段 |
| 窗口关闭 | 开 | 开 | 关(自动释放) | 关 | 未通关则重来:亲自踩 C 或重录 C 路 |

## 9. 边缘规则

| 编号 | 规则 |
| --- | --- |
| E-31 | 时间锁到期自动释放,**不看脚下是否有人**(回声踩不住它)——本关核心规则 |
| E-32 | 重新激活必须先离开再进入;持续站立不会重置倒计时 |
| E-33 | 窗口关闭时玩家在门洞内 → 门防夹规则生效;重开门需重触发时间锁 |
| E-34 | 玩家已进入出口区后窗口关闭:通关已在进入瞬间成立,不受影响 |
| E-35 | 重置:倒计时清零、三开关/门/回声/记录全量复位,时间锁重新武装 |
| E-36 | 回声站在 C 上到期释放后,回声仍停留在末帧(无害,视觉上"守着一个失效的锁") |
