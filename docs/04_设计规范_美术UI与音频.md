# 04 设计规范:美术、UI 与音频

> 版本 v1.0 | 状态:定稿 | 日期 2026-11-04
> 上位文档:第六章「美术与音效规范」、第七章「用户界面设计」

## 1. 美术总则

- 主题:**低饱和度科幻像素风**,氛围安静、神秘、冷色调,地下实验室空间感。
- 内部渲染分辨率 **640×360**,窗口整数倍缩放(`canvas_items` + `keep`),**禁止非整数缩放导致像素模糊**。
- Demo 阶段使用**占位素材**(色块/几何/引擎原生绘制),但:节点结构、Sprite 尺寸、原点位置(脚底)必须按最终规格预留,保证后期换素材零改代码。

## 2. 色彩规范(全局唯一权威色板)

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景 | `#111827` | 深蓝黑 |
| 建筑结构 | `#394B5D` | 低饱和蓝灰 |
| 玩家角色 | `#E5E7EB` | 浅灰白 |
| 时间回声 | `#45D9F2` | 青蓝色(半透明,alpha≈0.6) |
| 激活机关 | `#F4D35E` | 明亮黄(指示灯/激活态) |
| 危险区域 | `#D95D5D` | 暗红(本 Demo 关卡内暂不出现,预留) |

用色规则:场景主体只用背景+建筑结构两色;**彩色只用于语义**(黄=可交互/激活,青=回声,红=危险),不得装饰性滥用。

## 3. 素材规格

| 素材 | 规格 | 原点 | 动画 |
| --- | --- | --- | --- |
| 玩家角色 | 32×48 px,四向(下/上/左/右) | 脚底中心 | idle(2帧)/ walk(4帧)/ interact(2帧) |
| 回声 | 与玩家同图集,运行时整体染色 `#45D9F2` + alpha 0.6 | 同玩家 | 同玩家,后续可加扫描线 shader |
| 地板 tile | 64×32 等距菱形 | 菱形底部中心 | 无 |
| 墙体 tile | 64×64(含立面高度) | 底部中心 | 无 |
| 压力开关 | 64×32 底座,两态(灰/黄) | 底部中心 | 激活时底座下沉 2px |
| 安全门 | 单格宽 64×96,两态(闭/开) | 底部中心 | 开启位移动画(上移或两侧) |
| 时间记录装置 | 64×64 终端台 | 底部中心 | 屏幕闪烁 2 帧 |

- 命名:`主体_状态_序号.png`(03 §2);图集优先单文件(sprite sheet)。
- Demo 占位实现:允许用 `Polygon2D`/`ColorRect`/纯色 Sprite 代替上表素材,但**尺寸与原点必须一致**。

## 4. UI 规范

### 4.1 布局(CanvasLayer,锚点定位,640×360 设计稿)

```
┌────────────────────────────────────────────┐
│ 第一章·第1关 第一次回声              回声 ●●○ │ ← 左上:章节关卡名;右上:回声数(上限3)
│                                            │
│              (游戏画面)                     │
│                                            │
│        [正在记录 ▓▓▓▓░░░░ 0:12.4]           │ ← 底部中央:记录时间轴(三态,见4.2)
│   WASD移动 · R记录 · 空格回声 · X删除 · Backspace重置 │ ← 底部:键位提示(常驻)
└────────────────────────────────────────────┘
```

### 4.2 记录时间轴三态(FR-012,对应上位文档 §7.3)
| 状态 | 表现 |
| --- | --- |
| 普通 | 隐藏或暗色(不干扰画面) |
| 记录中 | 时间轴从 0 填充至 30s,颜色 `#F4D35E`,附剩余秒数 |
| 回放中 | 显示回放进度条,颜色 `#45D9F2` |

### 4.3 暂停菜单(Esc)
项:继续游戏 / 重新开始本关 / 退出游戏。暂停时 `get_tree().paused = true`,UI 层 `process_mode = PROCESS_MODE_WHEN_PAUSED`。

### 4.4 通关界面
半透明黑罩 + 文案(见 05 §6)+「按任意键重玩」。

### 4.5 字体与文案
- 使用开源中文像素字体(候选:Fusion Pixel / Zpix;占位阶段可用默认字体,字号 ≥ 12px 设计稿)。
- 所有面向玩家的文案**集中定义在常量文件 `scripts/ui/ui_text.gd`**,禁止散落硬编码;第一关全部文案见 05 §6。

## 5. 音频规范

| 项 | 规范 |
| --- | --- |
| 格式 | SFX 用 WAV(短音效);BGM 用 OGG |
| 命名 | `sfx_<对象>_<事件>.wav`,如 `sfx_switch_on.wav`、`sfx_door_open.wav` |
| 清单(Demo 可选) | 环境底噪、移动、记录开始/结束、回声生成、机关激活、门开、关卡完成 |
| 播放 | 经统一 `AudioManager` 节点(demo 可用 AudioStreamPlayer2D 就地播放,管线预留) |
| Demo 策略 | 音频可整体缺席,但触发点代码位置预留(注释标记 `# TODO(audio)`) |
